# Welcome to ADeUX

### 

ADeUX (ArkOS Debian User Experience) is an independent community-driven Linux distribution based on dArkOS, focused on supporting and improving the Game Console line of retro gaming handhelds.

ADeUX is the successor to the former ArkOS-R3XS project, which was developed as a customized ArkOS image for the Game Console range of devices. Following the sunset of ArkOS, ArkOS-R3XS was also sunset.

Development has since continued using dArkOS as the base, bringing forward the experience and device-specific work from the previous project while allowing ADeUX to develop independently.

## What is ADeUX?

ADeUX is an independent community-driven Linux distribution based on dArkOS, focused on supporting and improving the Game Console line of retro gaming handhelds.

ADeUX is the successor to the former [ArkOS-R3XS](https://github.com/AeolusUX/ArkOS-R3XS) project, which was developed as a customized ArkOS image for the Game Console range of devices.

ADeUX takes the latest available dArkOS release and applies additional modifications, configurations, fixes, and improvements specifically for the supported Game Console devices.

The project aims to provide:

1. **Hardware-specific improvements**
2. **Performance and stability**
3. **Easy updates**
4. **Customizability**
5. **An enthusiast-focused experience**

## Supported Devices

ADeUX is focused on the **Game Console** range of retro gaming handhelds.

Currently supported devices include:
- R33S
- R35S
- R36S
- R36S Plus
- R36H
- R45H
- R46H
- R42 Pro

Additional Game Console devices may be supported as development continues.

## Relationship to dArkOS

ADeUX is an independent project based on dArkOS.

dArkOS remains an actively developed project and provides the base from which ADeUX is built. ADeUX adds its own device-specific modifications, configurations, scripts, and improvements for the Game Console range.

For issues specific to ADeUX, please use this repository rather than contacting the dArkOS maintainer.

## Building ADeUX

ADeUX is currently distributed as modified prebuilt images.

The release process begins with the latest dArkOS image, which is then modified with ADeUX-specific changes for the supported Game Console hardware.

ADeUX is not currently built from source.
